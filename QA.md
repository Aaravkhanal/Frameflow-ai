# 🧪 FrameFlow AI Quality Assurance (QA) Guide

**Created & Engineered by Aarav Khanal**

## Asset Handling Verification
- Extracts accurate assets from screenshots — logos, hero images, feature icons.
- Ensures extracted crops are pixel-accurate and rendered in output code.
- Verifies uploaded logos are preserved verbatim without distortion.
- Inspects rendered HTML inside the preview pane.

## Core Multi-Modal Capabilities
- **Screenshot → Code**: Analyzes PNG/JPG screenshots and converts them to clean code.
- **Figma → Code**: Renders Figma nodes via REST API and converts to component code.
- **URL → Code**: Captures website layout and extracts structure into clean HTML/Tailwind.
- **Screen Recording → UI**: Ingests MP4/WebM recordings and parses user interaction flows.
- **Multi-Model Consensus**: Synthesizes output from OpenAI, Anthropic Claude, and Google Gemini.
