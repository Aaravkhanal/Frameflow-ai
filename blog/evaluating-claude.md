# ⚡ Evaluating Vision Models for FrameFlow AI

**By Aarav Khanal (Lead Engineer)**

In building **FrameFlow AI**, evaluating LLM vision accuracy (GPT-5.5, Claude Opus, Gemini 3.1 Pro) across screenshot replication is critical.

---

## 🎯 Evaluation Benchmark Methodology

1. **Evaluation Dataset**: 16 complex UI screenshots covering responsive landing pages, mobile dashboards, and data tables.
2. **Replication Accuracy Metric**: Visual fidelity rating from 0 to 4 assessing layout structure, typography, spacing, and CSS styling.
3. **Execution Script**: Parallel benchmark execution script in `backend/run_evals.py`.
